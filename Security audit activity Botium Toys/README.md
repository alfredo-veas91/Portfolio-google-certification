# Botium Toys: IT Security Audit & Compliance Assessment

> [!NOTE] ACTIVITY MADE IN JULY 2026

## 📌 Project Overview
This project presents an internal IT security audit and risk assessment conducted for **Botium Toys**, an expanding e-commerce and retail toy company. 

The primary goal of this audit is to evaluate the company's current security posture, identify vulnerabilities in asset management, and determine adherence to key regulatory frameworks (**PCI DSS**, **GDPR**, and **SOC 1/SOC 2**) using the **NIST Cybersecurity Framework (NIST CSF)**.

---

## 🛠️ Key Deliverables
* **Scope & Risk Assessment Review:** Evaluation of IT-managed assets, current threat landscape, and risk scoring.
* **Controls Checklist:** Assessment of 13 critical security controls (technical, administrative, and physical).
* **Compliance Checklist:** Gap analysis for PCI DSS, GDPR, and SOC 2 frameworks.
* **Prioritized Recommendations:** Actionable roadmap for stakeholders to mitigate operational risks and prevent legal/financial penalties.

---

## 📂 Audit Findings Summary
* **Current Risk Score:** 8 / 10 (High)
* **Main Vulnerabilities Identified:** Lack of data encryption (PII/SPII and payment data), absence of least privilege access controls, missing disaster recovery/backup plans, and uncentralized password management.
* **Key Compliance Gaps:** Non-compliance with PCI DSS and key GDPR data privacy controls.

---

## 🚀 Recommended Actions
1. **Critical:** Implement data encryption at rest and in transit (PCI DSS / GDPR).
2. **Critical:** Enforce Least Privilege and Separation of Duties.
3. **Critical:** Establish automated data backups and a Disaster Recovery Plan (DRP).
4. **Medium:** Deploy an Intrusion Detection System (IDS) and schedule legacy system maintenance.
