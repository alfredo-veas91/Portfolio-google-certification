Este repositorio funciona como mi bitácora personal y registro de laboratorios. Aquí documento los hallazgos, notas de estudio y conclusiones clave sobre las diferentes herramientas y conceptos de ciberseguridad que voy explorando.

## Estructura del Repositorio

- **`notas/`**: Apuntes detallados sobre conceptos teóricos, marcos de trabajo (como NIST o ISO) y metodologías.
- **`laboratorios/`**: Registro de prácticas, evidencias y comandos utilizados en entornos controlados.
- **`herramientas/`**: Resúmenes y guías de uso rápido sobre las distintas tecnologías y software analizados.
